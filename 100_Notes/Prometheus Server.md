> 拉取（Pull） ──> 存储（TSDB） ──> 计算（Rules） ──> 提供查询（PromQL）

# 核心架构

Prometheus Server 内部主要由以下三个核心模块协同工作：

```
                ┌──────────────────────────────────┐
                │            Prometheus Server     │
                │                                  │
┌──────────┐    │  ┌──────────────────┐            │
│ 监控目标 ├────┼─►│ 1. 抓取引擎      │            │
│ (Targets)│Pul │  │   (Scrape Loop)  │            │
└──────────┘    │  └────────┬─────────┘            │
                │           │ 写入                  │
                │           ▼                             │
                │  ┌──────────────────┐   触发告警        │   ┌──────────────┐
                │  │ 2. 时序数据库     ├──────────────────┼─────►│ Alertmanager │
                │  │   (TSDB Engine)  │   (Rule Engine)  │      └──────────────┘
                │  └────────▲─────────┘                   │
                │           │ 读取                        │
                │  ┌────────┴─────────┘                   │
                │  │ 3. 查询引擎      │                   │
                │  │   (PromQL Engine)│                   │
                │  └────────▲─────────┘                   │
                └───────────┼─────────────────────────────┘
                            │ HTTP API 查询
                     ┌──────┴──────┐
                     │ Grafana / UI│
                     └─────────────┘
```

1. 抓取引擎 (Scrape Engine / Scrape Loop)
